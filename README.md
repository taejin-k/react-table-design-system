# React Table Design System

Ant Design에 의존하지 않고 React, TypeScript, Tailwind CSS로 구현한 데이터 테이블입니다.

## Features

- 전역 검색과 열별 필터
- 3단계 정렬(오름차순, 내림차순, 해제)
- 페이지네이션과 행 선택
- 확장 행과 인라인 편집
- 고정 열과 가로 스크롤
- 열 표시/숨김
- 로딩, 오류, 빈 상태
- 키보드 포커스 및 접근성 레이블
- 제네릭 TypeScript API와 커스텀 셀 렌더러

## Run

```bash
npm install
npm run dev
```

## Verify

```bash
npm test
npm run lint
npm run build
```
